# MC102 - 2026 S2 - Turmas T e U

Este repositório inclui os códigos escritos durante as aulas teóricas das turmas T e U da disciplina MC102 no segundo semestre de 2026 na UNICAMP.

Para ver os códigos, clique na pasta com a data da aula ministrada e escolha o código que deseja ler. Para rodar os códigos, você pode copiar e colar o conteúdo do arquivo em um ambiente de desenvolvimento.
